# Product snapshot — v0.5.0 (2026-10-21)

Current state of the product after the M6 "API & determinism contract"
milestone. Refreshed after every release; this file is the "what exists today"
answer to product questions.

## In one sentence

A deterministic, zero-dependency fingerprint computation engine in Zig 0.14.1:
a TypeScript browser SDK collects 102 signals and POSTs a versioned
SignalPackage to an ingress; stateless Zig workers (Docker containers) compute
the canonical fingerprint, risk, and entropy; results fan out over AMQP to the
fraud platform (Go, separate repo). M6 froze the wire ABI and the SDK 1.0
surface and put cross-browser determinism under CI.

## Testing posture

- `zig build test --summary all` → **491/491** (468 unit + 23 integration).
- `npm run verify` (SDK) → typecheck + type-level surface + **28/28** runtime
  tests.
- Cross-browser matrix: 3 browsers × 3 environments, zero drift against the
  checked-in golden digests; CI fails on any decodable difference.
- Golden fixture `signal-package-v2.bin` pins the canonical digest across Zig,
  worker, and TS tests.

## Release surface

- GitHub Release: WASM infra artifact + four native tarballs
  (linux x86_64/aarch64 musl, macOS x86_64/aarch64).
- GHCR images: `fingerprint-worker` and `fingerprint-ingress`.
- npm: SDK pre-release `1.0.0-rc.1` under `@next`; `latest` remains `0.4.1`
  until the SDK 1.0.0 final. Engine tags no longer publish npm.
