## M6 review items

- [x] **Wire versioning ADR merged.** `specs/decisions/0012-versioning-compatibility-adr.md`
      is **Adopted (2026-09-17)**; §5 carries the frozen SemVer/deprecation
      policy. ABI pinned by `tests/serialization/abi_pin_test.zig`
      (header + v1 + v2 goldens, decode round-trip).
- [x] **Registry guard.** `src/model/feature.zig` has a 102-entry anchor table
      and a `comptime` `@field` check; renumbering or reclaiming an id fails the
      build (`m6-registry-lock`). Stable-core subset locked behind a
      `core_version = 1` comptime guard.
- [x] **Capability negotiation.** The optional `signals` tail appended to the
      SignalPackage v2 body is emitted by the SDK (sorted, deduped), tolerated
      when absent by the engine, and never hashed. Tolerant lookup/decode land
      in `src/model` + `src/serialization` (`m6-tolerant-lookup`,
      `m6-tolerant-decode`); regression pinned by
      `tests/serialization` capability-tail tests.
- [x] **Cross-browser digest green.** The 3×3 runner (Chromium/Firefox/WebKit
      across three environments) matches the checked-in golden digests with zero
      drift; CI fails on any diff (`Browser Matrix`). The per-signal triage and
      the stable-core contract are recorded in
      `specs/quality/signal-determinism-matrix.md` and
      `specs/quality/signal-determinism-contract.md`.
- [x] **SDK API frozen.** `specs/product/SDK_API_SURFACE.md` enumerates the 1.0
      surface; `packageSignals()`/`PackageResult` and
      `CollectResult.status`/`error` are in place; no public symbol has been
      added since the D1 freeze. Contract suites:
      `tests/clients/browser/api_surface.test.mjs`,
      `contract.test.mjs`, `types/surface.ts`.
