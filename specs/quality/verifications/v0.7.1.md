Patch release closing the two actionable findings from the M8 review  
(`specs/verifications/REVIEW-m8.md`). Plan: `specs/planning/v0.7.1.md`.

## Readiness truthfulness (R2)

- [x] `WorkerPool` stamps each slot on connect and after every successful exchange (`Slot.last_used_ns`).
- [x] `refresh` reconnects slots with no client **and** drop-and-reconnects connections idle past `pool.idle_probe_after_ns` (30 s), so a dead-but-connected worker cannot keep readiness green.
- [x] The ingress idle tick calls `refresh` on every tick, not only when the pool is empty, and publishes the result to `fpkg_ingress_worker_pool_healthy` / `/readyz`.
- [x] Regression tests: `tests/cmd/pool_test.zig` (6 tests) pin that a dead connection is dropped by the TTL re-probe, that a connection younger than the TTL is trusted, and that an unreachable seed reports zero.
- [x] Manual UAT (2026-11-13): ingress + worker on loopback, scrape before kill `fpkg_ingress_worker_pool_healthy 1` / `readyz 200`; after killing the worker and idling 35 s, gauge `0` and `readyz 503` `{"ready":false,"component":"ingress","dependency":"worker_pool"}`.
